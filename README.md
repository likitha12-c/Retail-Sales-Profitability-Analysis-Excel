# Retail Sales & Profitability Analysis Using Microsoft Excel

##  Project Overview

This project focuses on analyzing retail sales and profitability using Microsoft Excel. The objective is to evaluate business performance, identify sales trends, understand profitability, and generate actionable insights to support data-driven decision-making.

##  Tools & Technologies Used

- Microsoft Excel
- Pivot Tables
- Excel Formulas (SUMIF, COUNTIF, AVERAGEIF, VLOOKUP)
- Charts and Data Visualization
- Data Cleaning and Preprocessing
- Interactive Dashboard and Slicers

##  Project Objectives

- Analyze overall retail sales performance.
- Evaluate profitability across products and categories.
- Identify regional sales trends and performance.
- Analyze key business performance indicators (KPIs).
- Develop an interactive Excel dashboard.
- Generate meaningful business insights and recommendations.

##  Project Workflow

1. Raw Data Collection
2. Data Cleaning and Preprocessing
3. Data Overview and KPI Analysis
4. Pivot Table Analysis
5. Formula-Based Analysis
6. Data Visualization
7. Interactive Dashboard Creation
8. Business Insights and Recommendations

##  Workbook Contents

| Sheet Name | Description |
|---|---|
| Raw_Data | Original dataset |
| Clean_Data | Cleaned dataset |
| 01_Data_Overview | Dataset overview |
| 02_KPI_Analysis | Key performance indicators |
| 03_Pivot_Analysis | Pivot table analysis |
| 04_Formula_Analysis | Excel formula-based analysis |
| 05_Charts | Data visualizations |
| 06_Dashboard | Interactive dashboard |
| 07_Business_Insights | Key business findings |
| 08_Recommendations | Business recommendations |

##  Key Analysis Areas

- Total Sales and Profit Analysis
- Regional Performance Analysis
- Category and Sub-category Analysis
- Customer Segment Analysis
- Shipping Mode Analysis
- Yearly Sales Trends
- Profit Margin Analysis

##  Project Outcome

Developed an Excel-based retail sales and profitability analysis workbook featuring data cleaning, KPI calculations, Pivot Tables, visualizations, and an interactive dashboard. The project provides business insights and recommendations to support better decision-making.
